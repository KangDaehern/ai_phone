## 권장 구성

### 전화 서비스

우선 검토안은 기존 대표번호, 전화 서비스, 내선과 전화기를 그대로 쓰면서 AI가 전화 흐름에 들어갈 수 있는지만 확인하는 것이다. 처음부터 기업 인터넷전화 10회선을 다시 가입하거나 IP 전화기 10대를 교체하지 않는다.

### PBX, Centrex와 SIP 트렁크의 의미

- `PBX`는 대표전화로 들어온 전화를 각 직원의 내선으로 나누고, 돌려주기·당겨받기·통화중·무응답 처리를 담당하는 전화 교환 시스템이다. 사무실 안에 장비가 있으면 사설/구내 PBX라고 부른다.
- `Centrex` 또는 클라우드 PBX는 그 교환기 기능을 통신사 서버에서 제공하는 서비스다. 사무실은 전화기만 두고 내선·돌려주기 기능을 사용한다.
- `SIP`는 인터넷으로 전화 연결을 제어하는 표준 프로토콜이다.
- `SIP 트렁크`는 사무실 PBX 또는 AI 전화 서버와 통신사의 공중전화망을 연결하는 인터넷 기반 전화 회선이다. 기존 대표번호로 걸려온 전화를 AI/PBX 서버에 넣고 다시 직원 내선으로 보내는 통로라고 이해하면 된다.

이미 내선과 전화 돌려주기가 동작한다면 어떤 형태의 PBX가 이미 존재한다. 필요한 것은 10회선 신규 가입 자체가 아니라, 현재 PBX 또는 통신사 서비스가 AI 서버와 연결될 수 있는 SIP/API 접점을 제공하는지 확인하는 것이다.

그러나 일반 Centrex 가입만으로 AI 연동이 보장되지는 않는다. 계약 전에 통신사 또는 구축업체로부터 다음 항목을 서면 확인해야 한다.

- 외부 SIP URI 또는 고객 소유 SIP 서버로 인바운드 전달 가능
- 발신번호 전달
- SIP REFER 또는 이에 준하는 내선 전환 API
- 담당자 무응답/통화중 이벤트 제공
- 전환 후 약 10초 무응답 시 AI 쪽으로 통화 회수 가능
- 동시 통화 채널 수와 채널 추가 비용
- 대표번호 유지 또는 번호이동 가능
- 장애 시 지정 번호로 우회 착신

이 요구가 충족되지 않으면 기존 대표번호를 유지하거나 번호이동한 뒤 `SIP 트렁크 + 고객 소유 Asterisk/FreeSWITCH PBX` 구성을 선택한다. 외부 SIP 연동을 막는 폐쇄형 Centrex에 먼저 가입하면 AI 연결을 위해 다시 교체할 수 있으므로, 가격보다 연동 권한을 먼저 확인한다.

### 통신사 공개 자료 확인 결과

- KT 일반 Centrex 공개 페이지에서는 내선, 순차·동시 착신, 당겨받기 등은 확인되지만, 임의의 외부 AI SIP URI로 직접 전달하고 무응답 후 회수하는 기능은 공개 명세에서 확인되지 않았다.
- KT 커스텀콜센터 자료에서는 기존 구내교환기와 PRI/SIP 내선 연동, 추가 SIP 중계선 트렁크 및 Call Control API 지원이 명시되어 있다. 따라서 KT 계열에서 기술 구현 경로는 존재하지만, 소규모 10인 사무실의 일반 Centrex 계약에 같은 권한이 제공되는지는 별도 견적·기술 협의가 필요하다.
- LG U+는 고급형 Centrex에서 내선·돌려주기를 제공하고, 교환기 구축형 DCS에서 Open API와 솔루션 연동을 명시한다. 그러나 공개 자료만으로 OpenAI SIP 직접 전달과 무응답 회수까지 확정할 수 없다.
- SK브로드밴드는 교환기 설치형 상품에서 DID/DOD 중계선, 중계선 착신전환·이중화 및 IP-PBX 사용을 공개하고 있다. 역시 외부 AI SIP 직접 연결의 세부 조건은 기술 협의가 필요하다.

따라서 현재 공개 정보만으로 통신사 하나를 “전체 요구사항 지원 확정”이라고 선정할 수는 없다. 가장 가능성이 높은 협의 대상은 일반 Centrex 판매창구가 아니라 통신사의 기업 IP-PBX/SIP 트렁크 또는 컨택센터 기술영업 부서다. 후보 업체에 동일한 시험 시나리오를 주고 실제 테스트 콜로 검증한다.

## 무엇을 구매하거나 가입할 것인가

### 기존 장비 우선 재사용

| 항목 | 수량 | 기획 예산 |
|---|---:|---:|
| 기존 IP 전화기 | 10대 | 호환되면 추가 비용 없음 |
| 기존 24시간 서버용 Windows PC | 1대 | 성능·안정성 충족 시 추가 비용 없음 |
| 기존 UPS | 1대 | 서버·PBX·네트워크 장비까지 보호하면 추가 비용 없음 |
| 기존 공유기·스위치 | 1식 | 포트·품질·보안 요건 충족 시 추가 비용 없음 |
| 전화 연동 장치/PBX | 필요 시 | 현재 환경 조사 후 견적 |

UPS는 예상한 대로 정전 시 일정 시간 전원을 공급하는 무정전 전원장치다. 이미 있다면 새로 살 필요가 없지만, 서버 PC뿐 아니라 PBX/게이트웨이·공유기·스위치까지 연결되어야 정전 중에도 전화 시스템이 유지된다.

공유기는 사무실 인터넷을 내부 장비에 배분하고 방화벽/NAT를 담당하며, 스위치는 서버·IP 전화기·PC를 유선망에 연결한다. AI 때문에 무조건 새로 구매하는 품목은 아니다. 기존 장비의 빈 포트, 동시 통화 트래픽, QoS, VLAN, 방화벽의 SIP/WebSocket 허용 및 PoE 용량이 충분하면 그대로 사용한다.

### 필수 또는 유력한 가입 서비스

1. 기존 대표번호와 인터넷·내선전화 계약 유지
2. 현재 전화 서비스에 추가 가능한 SIP 트렁크/API/AI 연동 옵션, 또는 필요할 때만 호환 서비스로 변경
3. 실시간 음성 AI API
4. 카카오 비즈니스 채널과 알림톡 공식 딜러 서비스
5. 선택적으로 클라우드 백업·모니터링 서비스

안정성을 높이려면 별도 LTE/5G 라우터나 제2 인터넷 회선을 장애 우회용으로 추가한다.

## 월 운영비 추정

### 전화와 인터넷

기존 인터넷·전화·대표번호 비용은 현재도 지출 중인 운영비이므로 AI 도입의 추가 비용에서 제외한다. 추가 비용은 SIP 트렁크, 동시 통화 채널, PBX/API 연동 옵션과 현장 설정비다. 이 가격은 통신사 공개 소매 요금표에서 요구사항 단위로 확인되지 않아 견적이 필요하다.

### 카카오 알림톡

카카오는 알림톡을 공식 딜러사를 통해 제공한다. 공개 단가의 한 예로 SOLAPI는 월 기본료와 기본 API 비용 없이 알림톡 1건당 13원(VAT 별도, 월 9,999건 이하)을 제시한다.

통화 한 건당 담당자에게 알림톡 한 건을 보낸다고 가정하면:

| 하루 전화 | 월 영업일 | 월 발송량 | 13원 기준(VAT 별도) |
|---:|---:|---:|---:|
| 30건 | 22일 | 660건 | 8,580원 |
| 50건 | 22일 | 1,100건 | 14,300원 |
| 100건 | 22일 | 2,200건 | 28,600원 |
| 150건 | 22일 | 3,300건 | 42,900원 |

따라서 이 사무실 규모에서는 알림톡 예산을 보통 월 1만~5만원 정도로 보면 된다. 실패 시 SMS/LMS 대체 발송, 메시지 두 번 전송, 딜러 부가상품을 사용하면 증가한다. 템플릿 심사와 카카오 비즈니스 채널 개설이 필요하다.

### 실시간 음성 AI

OpenAI의 공개 가격상 GPT-Realtime-1.5 오디오 토큰은 입력 $32/백만 토큰, 출력 $64/백만 토큰이다. 실제 비용은 고객과 AI의 발화 비율, 침묵, 대화 턴 수, 프롬프트 길이와 캐시 사용에 따라 달라지므로 통화 분당 고정 단가로 확정할 수 없다.

분당 계획값의 근거는 다음과 같다.

1. OpenAI 공식 가격은 오디오 입력 $32/백만 토큰, 오디오 출력 $64/백만 토큰이다.
2. 과거 OpenAI가 공개한 Realtime 환산값에서 오디오 입력은 약 600토큰/발화 1분, 출력은 약 1,200토큰/발화 1분으로 역산된다. 현재 모델의 토큰화가 동일하다고 보장되는 것은 아니므로 추정에만 사용한다.
3. 고객이 전체 시간의 60%, AI가 40% 말하는 1분 통화를 가정하면 `600×0.6×$32/1M + 1,200×0.4×$64/1M ≈ $0.042`다.
4. 환율을 1달러당 약 1,380원으로 보면 순수 오디오가 약 58원/통화 1분이다.
5. 시스템 프롬프트, 대화 이력의 반복 입력, 텍스트 토큰, 도구 호출, 말 끊기 및 토큰화 차이를 고려해 계획값을 약 60~150원/AI 통화 1분으로 잡는다.

이는 공식 고정 분당 요금이 아니라 공개 토큰 가격을 이용한 추정이다. 파일럿에서는 API 응답의 실제 input/output/cached token을 통화별로 저장해 원가를 다시 계산한다. 등록 번호를 바로 연결하여 AI가 말하지 않는 통화는 AI 음성 비용이 거의 발생하지 않는다.

| AI 응대량 | 월 AI 통화시간 | 기획 예산 |
|---|---:|---:|
| 하루 30분 | 660분 | 약 4만~9.9만원 |
| 하루 60분 | 1,320분 | 약 7.9만~19.8만원 |
| 하루 120분 | 2,640분 | 약 15.8만~39.6만원 |

환율, 모델 가격과 실제 토큰 사용량에 따라 달라지므로 운영비 상한, 통화별 최대 응대 시간, 월 예산 알림을 반드시 둔다.

### 전체 월 운영비 계획값

| 항목 | 월 예상 |
|---|---:|
| 기존 인터넷·전화·대표번호 | 기존 지출이므로 추가 비용 0원으로 계산 |
| SIP/PBX/API 연동 옵션 | 통신사 견적 필요 |
| 실시간 음성 AI | 4만~40만원 |
| 알림톡 | 1만~5만원 |
| 백업·모니터링·선택 클라우드 | 2만~15만원 |
| 확인 가능한 추가 운영비 소계 | 약 7만~60만원 + 통신사 연동료 |

보통 사용량의 초기 목표 예산은 기존 전화·인터넷 비용을 제외하고 월 10만~35만원에 통신사의 SIP/PBX 연동료를 더하는 수준으로 시작할 수 있다. AI 통화가 하루 2시간에 가까우면 월 40만원 이상으로 올라갈 수 있다. 유지보수 계약과 소프트웨어 개발비는 별도다.

## 개발비

직접 개발하면 현금 지출은 주로 장비와 API 사용료지만 개발 시간이 필요하다. 외주 개발은 PBX 연동, 관리자 화면, 개인정보 보호, 장애 대응과 현장 설치 범위에 따라 편차가 매우 크므로 요구사항 확정 전 금액을 제시하기 어렵다. 견적서는 최소한 다음 항목을 분리해서 받아야 한다.

- 전화/PBX 구축 및 현장 설치
- AI 통화 및 라우팅 소프트웨어
- 직원·고객 관리 화면
- 알림톡 연동
- 녹취·보관·권한·감사 기능
- 장애 우회와 모니터링
- 월 유지보수 및 긴급 대응 시간
