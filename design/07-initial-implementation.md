# 초도 구현 명세

## 목표

전화 장비, OpenAI Realtime API와 카카오 알림톡이 계약되지 않은 상태에서도 담당자 라우팅 규칙과 통화 흐름을 로컬에서 검증한다.

## 더미 조직

- 대표: 홍사장, 내선 100
- 직원: 홍길원~홍길구, 내선 101~109
- 대표번호: 02-555-0100
- 직원별 담당 업체: 3개씩 총 27개
- 공통 업무: 부가세, 각종 세금 신고, 급여 처리, 4대보험과 기장

직원마다 업무 종류를 나누지 않고 담당 업체를 나눈다. 업체와 담당자의 관계가 라우팅의 핵심 기준이다.

## 라우팅 우선순위

1. 확정 스팸 번호 차단
2. 의심 스팸 키워드 검토 알림
3. 발신자가 특정 직원 또는 대표를 요청한 경우
4. 등록된 발신번호의 업체 담당자
5. 발신자가 말한 업체명의 담당자
6. 기타 문의 담당자 홍길구

직원이 부재 상태면 설정된 대체 담당자를 선택한다.

## 외부 연동 상태

- 전화/PBX: `DummyTelephonyAdapter`
- 음성 AI: `DummyVoiceAdapter`
- 카카오 알림톡: `DummyNotificationAdapter`

실제 연동 코드는 아직 호출하지 않으며 계약과 테스트 계정이 준비된 후 별도 어댑터로 추가한다.

## 확장성

`config/office.json`에서 대표를 제외한 직원 3~20명을 지원한다. 직원을 추가할 때 고유 ID, 이름, 내선, 상태, 별칭과 대체 담당자를 설정하고 업체의 `employee_id`를 연결한다.

Python 패키지는 프로젝트 루트의 `ai_phone`에 두어 `python -m ai_phone.cli` 명령이 별도 설치나 `PYTHONPATH` 설정 없이 프로젝트 루트에서 실행되도록 한다.

## 현재 제한

- 실제 음성을 인식하지 않고 CLI 인자로 구조화된 고객 정보를 받는다.
- 마이크 없는 테스트를 위해 고객 발화는 키보드로 입력하고, AI 응답은 Windows 내장 `Microsoft Heami Desktop` 한국어 TTS로 스피커에 재생하는 데모를 제공한다.
- 연결 전에 업체명과 발신자 성함을 필수로 확인한다. 등록 발신번호는 업체를 자동 식별하고 성함만 추가로 묻는다.
- 실제 전화 수신·전환을 하지 않는다.
- 실제 카카오톡 메시지를 발송하지 않는다.
- 콜백 업무함과 통화 이력은 아직 영구 저장하지 않는다.
- 업무시간, 휴일, DTMF와 관리자 웹 화면은 후속 구현 대상이다.
