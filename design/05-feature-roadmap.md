# 필수 기능과 단계별 적용 계획

아래 기능은 사용자 확인에 따라 모두 제품 필수 요구사항으로 확정한다. 구현 위험을 줄이기 위해 단계는 나누지만 최종 범위에서 제외하지 않는다.

## 1차 운영에 포함

### 담당자에게 연결 전 사전 안내

고객을 바로 연결하기 전에 담당자 전화기에 “A회사 홍길동, 부가세 신고 문의” 같은 짧은 음성 또는 화면 안내를 제공한다. 담당자는 수락, 거절, 대체 담당자 전환을 선택할 수 있다. 단순 연결보다 체감 효과가 큰 기능이다.

### 근무·부재 상태 연동

직원이 휴가, 외근, 회의 또는 통화 중이면 처음부터 대체 담당자로 보낸다. 초기에는 관리 화면의 수동 상태 버튼으로 시작하고 나중에 캘린더와 연동한다.

### 콜백 업무함

부재 메모를 알림톡으로만 끝내지 않고 담당자별 업무함에 쌓는다. `미확인 → 확인 → 회신 완료` 상태와 담당자 재배정을 지원해 전화 누락을 방지한다.

### 라우팅 신뢰도와 안전장치

- 고신뢰: 자동 연결
- 중신뢰: 고객에게 담당자를 한 번 확인
- 저신뢰: `etc` 담당자 연결

오연결을 직원이 한 번에 수정하면 다음 통화부터 번호·고객·담당자 관계에 반영한다.

### 업무시간·휴일·긴급전화 정책

업무시간 외에는 메시지를 받고, 신고 마감·장애·세무조사 등 미리 정한 긴급 키워드만 당직자에게 연결한다. 휴일과 임시 휴무 안내도 관리 화면에서 바꿀 수 있게 한다.

### 장애 우회와 수동 모드

관리자가 AI를 즉시 끄고 기존 방식으로 대표전화를 넘길 수 있는 비상 스위치를 제공한다. 인터넷, AI 또는 데이터베이스 장애 시에도 자동으로 `etc` 내선이나 휴대전화로 우회한다.

## 다음 단계에 유용

### VIP·차단·주의 번호

- 중요 고객은 우선 연결
- 확정 스팸 번호는 직원 전화기를 울리지 않고 자동 차단
- 의심 스팸은 용건을 최소 확인한 뒤 기본 스팸 검토 담당자에게 알림톡 전송
- 알림톡에 발신번호, 수신 시각, 분류 사유, 짧은 요약과 인증된 검토 화면 링크 포함
- 검토 화면에서 `스팸 확정`, `정상 번호`, `이번만 차단`, `주의 번호` 선택
- 스팸 확정 결과는 이후 통화부터 자동 차단 규칙에 반영
- 정상 번호로 수정하면 필요 시 고객사와 담당자를 함께 등록
- 기본 검토자는 막내 역할로 설정할 수 있고 관리자나 순환 담당자로 변경 가능
- 민원 이력이 있는 번호는 숙련 담당자에게 연결
- 발신번호 비표시 전화의 별도 확인 절차

### 통화 이력 화면

전화번호별 과거 담당자, 최근 용건, 미완료 콜백을 보여준다. AI에는 전체 녹취가 아니라 현재 응대에 필요한 최소 정보만 제공한다.

### 관리자 지표

- 시간대별 전화량
- 자동 직결률
- AI가 분류한 통화 비율
- 오연결률과 수정률
- 담당자 평균 응답시간
- 부재 메모의 회신 완료율
- AI 통화시간과 건당 비용

### 이름·회사명 사전

직원 이름, 고객사명, 세무 용어와 자주 틀리는 발음을 사전으로 관리하여 음성 인식 정확도를 높인다.

### DTMF 보조

음성 인식이 어렵거나 고객이 원할 때 “담당자 내선을 아시면 눌러주세요” 방식으로 전환할 수 있게 한다.

### 요약 품질 검증

요약에는 추측을 넣지 않고 발신자가 실제 말한 내용과 요청만 기록한다. 금액, 날짜, 사업자번호 같은 중요 값은 낮은 확신도를 표시하거나 고객에게 다시 확인한다.

## 장기 검토

- 직원용 모바일/Windows 앱
- 사내 일정·CRM·세무 업무 시스템 연동
- 통화 중 실시간 직원 지원 화면
- 다국어 응대
- 반복 문의에 한정된 안내 자동화
- 여러 지점의 대표번호 통합

AI가 세무 판단이나 확정적 답변을 대신하는 기능은 충분한 법률·품질 검증 전까지 범위에서 제외한다.
